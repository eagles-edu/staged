# Change Log — mod_gradelist

## Version 0.1.0 (2026021902)
- Initial release
- Live grade report across all courses an editing teacher teaches
- Student view showing their own grades across all enrolled courses
- Students grouped by letter grade: F, D, C, B, A, No Grade
- Collapsible sections, collapsed by default
- Colour coded group headers
- Respects Moodle course-level letter grade scales
- Sort by Last Name/First Name or Grade (Lowest First)
- Last course access column
- Open sections remembered across sort button clicks
- AMD JavaScript for collapse/expand behaviour
- Mustache template for output
- Full Moodle roles and capabilities support
- Privacy API implementation
- Backup and restore support
- Default name and description pre-filled on activity creation
- Custom plugin icon and monologo
